# 快速开始

## 安装

Lexora 目前通过 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 分发 beta 版（社区插件目录上架筹备中）：

1. 在 Obsidian 第三方插件市场安装并启用 **BRAT**
2. BRAT 设置 → **Add beta plugin** → 输入 `ClareYu-ZZZ/Obsidian-Lexora`
3. 版本选 **Latest version**，勾选安装后启用 → **Add Plugin**

以后每次发版，重启 Obsidian 即自动更新。

## 第一篇教程

1. 打开左侧 Lexora 图标 → **订阅** 页，从推荐源添加一个（如 BBC 6 Minute English），或粘贴任意 RSS / 播客 / YouTube 频道链接
2. 在条目卡片上点 **生成教程**：文章直接生成；带音频的条目自动逐句对齐；YouTube 视频自动抓字幕
3. 生成的学习笔记在 `50-Resources/Lexora/<日期>_<标题>/` 下：生词表、长难句、全文分段，每段带 ▶ 原声区间播放

::: tip 生成额度
免费版每月可生成 5 篇教程，Pro 为 20 篇，每月 1 日重置。
:::

## 收词与复习

- 阅读任意笔记时，词库内的词自动高亮，悬停（手机上轻点）出词卡，一键收入词本
- **复习** 页按 FSRS 调度出题，7 种模式可在词本的复习设置里勾选
- **统计** 页看连续打卡、词汇量估算与复习曲线

## 跟读训练

打开教程笔记 → 播放器面板：

- 每句可循环区间播放；🎙 录音后自动与原声对比回放
- macOS 首次录音需要先用核心插件「录音机」触发一次系统麦克风授权并重启 Obsidian
- 手机端会弹系统麦克风授权，允许即可
