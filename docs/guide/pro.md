# Lexora Pro 与订阅

Lexora 是 open-core：仓库代码 MIT 开源，**免费版永久可用**。

## 免费版包含

- 订阅管理、文章 / 带字幕媒体的教程生成（每月 5 篇）
- 自建词库（1.1 万词）+ 例句库、高亮、悬停词卡、词本
- 欧路词典双向同步
- FSRS / SM-2 / Leitner 复习，4 种基础模式
- 播放器（区间播放、跟读录音）、统计打卡
- worker 的 Piper TTS

## Pro 解锁

| 能力 | 免费 | Pro |
|---|---|---|
| 教程生成额度 | 5 篇/月 | **20 篇/月** |
| worker 转写（无字幕媒体） | — | ✓ |
| worker 原声切片 | — | ✓ |
| worker YouTube 下载 | — | ✓ |
| 高级复习模式（听音辨意 / 听写 / 例句拼写） | — | ✓ |

## 订阅与激活

- Pro 为**按月或按年订阅**，购买后获得形如 `LEXORA1.…` 的 license key
- **设置 → Lexora Pro → License key** 粘贴 → 应用，状态行显示到期日期
- key 为离线 Ed25519 签名校验：无账号、无联网激活、不回传任何数据；key 随 vault 同步到你的所有设备

## 试用

首次触发任意 Pro 功能时自动开始 **14 天全功能试用**（含 20 篇/月额度），到期自动回到免费版，数据不受影响。
